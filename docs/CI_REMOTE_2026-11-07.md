## Cấu hình workflow và required checks

Lượt đầu ở commit `6683747` bị từ chối trước khi tạo job vì dùng `runner.temp` tại cấp job env. Bản sửa chuyển cấu hình browser cache vào hai bước cần dùng. actionlint 1.7.12 đã kiểm checksum từ bản phát hành chính thức, từ chối workflow cũ và chấp nhận bản sửa. [Context của GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/contexts)

Repo là private, tài khoản hiện có quyền Admin và nhánh main chưa protected tại lần kiểm. Đã thử cấu hình năm required checks từ GitHub Actions, gồm `lint`, `secret-scan`, `verify (frontend)`, `verify (backend)` và `integration`. GitHub trả HTTP 403 với thông báo `Upgrade to GitHub Pro or make this repository public to enable this feature.` Required checks tiếp tục ở trạng thái mở theo điều kiện gói dịch vụ. [Phạm vi hỗ trợ branch protection](https://docs.github.com/en/rest/branches/branch-protection)

Các điều kiện UAT, dịch vụ thật, pilot và quyết định release được theo dõi riêng. [Cổng nghiệm thu](CONG_NGHIEM_THU_RELEASE.md)
